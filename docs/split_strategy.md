# Split strategy

- We train one logistic-regression classifier on 240 tomato images (30 per category) and measure accuracy once on 80 held-out images (10 per category). The eight categories exclude Target Spot and mosaic virus because their image identifiers have no matching leaf-map entries; this scope was selected before fitting. Sampling preserves the pinned PlantVillage color train/test lists; it does not randomly mix their images. Within each category/partition, seed-42 SHA-256 ranking selects one image per uniquely mapped leaf. Missing/ambiguous leaf mappings and any groups listed in both partitions are excluded; the pipeline also rejects cross-partition leaf or exact-content overlap.
- Scaling and classifier fitting use training features only. The 16 bins per RGB channel, regularization `C=1.0`, and sample sizes were fixed before measuring accuracy. There is no hyperparameter search or model selection on the held-out sample. Future tuning needs a separate validation set.
- These are controlled dataset photographs, whereas the proposed system would receive grower phone photos with varied backgrounds, lighting, and symptoms. The small, equally sampled evaluation set does not represent field conditions or natural class frequencies; its accuracy is only a first course baseline. Leaf separation depends on the publisher's mapping and cannot rule out all related scenes or near-duplicates.
