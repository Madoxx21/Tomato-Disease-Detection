# Baseline data

- **Source:** [mohanty/PlantVillage](https://huggingface.co/datasets/mohanty/PlantVillage), revision `9e97599868962bd0079b8db4b7f1efa9185fa1e7`. Credits: Sharada P. Mohanty, David P. Hughes, and Marcel Salathe, *Using Deep Learning for Image-Based Plant Disease Detection* (2016), [doi:10.3389/fpls.2016.01419](https://doi.org/10.3389/fpls.2016.01419).
- **Sample:** 320 original color tomato-leaf JPEGs across eight categories (including healthy and spider-mite damage): 30 training and 10 evaluation images per category. Target Spot and mosaic virus are excluded from this baseline because their image identifiers do not match entries in the supplied leaf map. Selection uses a fixed SHA-256 ranking with seed 42 and one image per mapped leaf. Missing or ambiguous leaf mappings and groups appearing in both source splits are excluded.
- **Obtaining it:** The baseline command downloads pinned Hugging Face split lists and leaf mappings, then only the selected images from the [upstream PlantVillage repository](https://github.com/spMohanty/PlantVillage-Dataset) linked by the dataset card, revision `7f7ecc7e1eaca78107e3affe7cb5abd9427e139a`. This avoids downloading the full Hugging Face archive. Internet access to Hugging Face and raw.githubusercontent.com is required on the first run; no login or manual extraction is needed.
- **Placement:** The script creates `data/plantvillage_sample/metadata/{splits,leaf_grouping}/`, `data/plantvillage_sample/images/raw/color/<Tomato___category>/<filename>.JPG`, and `data/plantvillage_sample/manifest.json` with selected paths, labels, partitions, leaf IDs, and image checksums. Everything under `plantvillage_sample/` is downloaded/generated and ignored by Git. Keep its layout unchanged for cached reruns; no images are committed.
- **Permission:** The Hugging Face card lists CC BY-SA 3.0; retain attribution and consult the source terms before redistributing data or derivatives. This project does not grant a separate image licence. No private grower photographs are included.
- **Preparation and checks:** Follow the root README to install dependencies and run the pipeline. It checks pinned metadata hashes, available class/group counts, JPEG format, RGB mode, minimum size, finite feature values, and absence of shared leaf IDs or identical image bytes across partitions. A corrupt cache causes an error; remove the affected cache file and rerun to download it again. Successful cached runs need no network.
